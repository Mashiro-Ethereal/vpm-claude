## 1. 一页结论

1. **【事实】五篇进度/过程奖励模型各自用不同的代理量定义“进度”，而且标签大多来自成功示范。**
   - SARM：人工阶段标注，阶段内按帧线性插值。
   - Robo-Dopamine：人工关键帧分段，每段分得相同的进度份额。
   - ProcVLM：VLM 自动分段，再按阶段内的视觉变化量分配进度。
   - DenseReward：仿真中按阶段和失败模式人为设计奖励曲线形状。
   - RoboReward：回合结束时的 1–5 分，失败样本靠改写指令和截断视频合成。

   失败或倒退的数据，或者靠合成得到（时间反转、截断、反事实指令、仿真扰动），或者干脆把含失败的轨迹排除在训练之外（SARM）。**没有一篇论证过自己的进度定义作为 RL 势函数时是否最优。**

2. **【事实】奖励接入 RL 的方式各不相同。**
   - Robo-Dopamine 和 FLORA 用 PBRS。
   - ProcVLM 用截断后的相邻进度差，权重 1.0，加 0.1 倍的成功奖励。
   - DenseReward 在仿真中把模型奖励按比例加到稀疏成功奖励上，真机上用“每步 −1 + 模型奖励”。
   - RoboReward 只在回合结束时给一次分。
   - SARM 主要用于给行为克隆数据加权（RA-BC）。

   于是，跨论文的“奖励模型 RL 对比”把奖励模型本身和接入方式混在了一起。最直接的例子是 ProcVLM 在 RoboTwin 上的比较：它对所有奖励模型都使用自己的进度差接入，包括 Robo-Dopamine（附录 F.1）；而 Robo-Dopamine 原文主张，正是这类非 PBRS 接入会造成“semantic trap”。

3. **“策略不变性”主张的前提各不相同。**
   - 【事实】Robo-Dopamine 的稀疏成功信号是由它自己的奖励模型判定的（Φ* ≥ 0.95 即视为成功），所以不变性只相对这个模型的成功定义成立；它的证明假设无限时域（附录 A.5）。
   - 【事实】FLORA 在加入里程碑的增广状态上证明不变性（定理 1）。
   - 【假设】Robo-Dopamine 的保守更新使进度依赖历史，证明没有覆盖这一点。FLORA 的里程碑之所以能避免“势函数坍塌”，靠的是有限时域截断时末端势项保留下来，这与不变性证明所需的前提不完全相容（见 §2.3 的方法缺陷）。

4. **【事实】离线奖励指标能否预测 RL 效用，这 8 篇里只有 RoboReward 给出了定量相关（r = 0.83，同族检查点）。** FLORA 给出的是方法层面的趋势一致。另外有一处反差：ProcVLM 表 3 中，Robo-Dopamine-8B 在成功轨迹排序（VOC_succ）上零样本最强（0.9095），但在 ProcVLM 的 RL 协议下，Robo-Dopamine 的两个变体都接近 SFT 基线（图 3）。不过这一结果同时受接入方式和适配数据的影响，不能单独归因于奖励模型。

5. **【事实】ORSO 和 LaRes 都靠真实任务成功或任务指标来挑选奖励，而这个信号在真实世界里本身就需要奖励模型或人来提供。** ORSO 的遗憾保证依赖“某个学习器始终占优、且平均回报单调增加”的假设（Assumption 4.2）。LaRes 换奖励时要靠奖励缩放和参数约束来防止策略崩溃；它的 Eureka 基线在同样的 1M 总步数内每轮从零开始训练（附录 B.1），所以这个对比条件偏向 LaRes。

6. **【假设】由此出现两个可检验问题：**
   - （a）在统一的 RL 接入协议下，哪种进度语义（时间、视觉变化、阶段完成度、成功概率、程序化几何量）最适合作为势函数？
   - （b）PBRS 候选的作用等价于给价值函数一个初始值（Wiewiora 2003；GAE §4）。那么，候选势函数在有限预算内的效用，能否用“Φ 与策略价值有多接近”这样的廉价量来预测？

   两个问题的新颖性都还需要核实。

   **更正：** 本文件早先提出“换势函数时精确平移 critic，让多个候选共享训练”。经核查这不成立：平移之后，切换不再起任何作用，见 §3.3。

## 2. 逐篇精读

### 2.1 Robo-Dopamine（Tan et al., 2025 arXiv；CVPR 2026）

**问题。** 作者认为已有过程奖励模型有两个缺陷：一是缺乏阶段感知，且只用单视角，在遮挡下判断不可靠；二是把奖励接入 RL 的方式理论上不严谨，会造成“semantic trap”。

**方法（【事实】）。**
- **GRM（通用奖励模型）。** 基于 RoboBrain 2.0 / Qwen2.5-VL，有 3B 和 8B 两个版本。输入任务文本，以及初始状态、目标状态、BEFORE、AFTER 四组多视角图像；输出一个量化的“hop”，即相对进度，取值 [−1, 1]（§3.1，附录图 6）。
- **标签构造。** 专家轨迹按人工标注的多视角关键帧分段。每段采样相同数量的点，所以全局进度 Φ(s_i) = i/M，每个阶段分得相同的进度份额。hop 的定义是：前进时按剩余距离归一化，后退时按已走距离归一化（式 2）。后退样本来自同一条专家轨迹中时间反转的状态对。采样时按分数分箱（25 箱）和时间间隔分箱（4 箱）做均衡，另有 5% 的零 hop 样本（附录 B.3）。
- **数据与算力。** 3,400 小时以上的视频，10 万条以上轨迹，350 个以上任务，共 35M 样本。约 60% 是真机数据，13% 是仿真，26% 是人类视频。训练用 128 张 H100，3B 版约 8 天，8B 版约 14 天（附录 B.2、C.1）。
- **多视角进度融合。** 把三种估计取平均：增量式（递推累加）、以初始状态为锚、以目标状态为锚（式 8）。可选的一致性检查用前向与后向估计的差异计算置信权重，并做保守更新（式 11）。这样得到的进度依赖于上一步的估计，因此是历史依赖的。
- **Dopamine-RL。** 先用一条示范对 GRM 做 SFT。奖励写成 `r = r_gold + γΦ*(s′) − Φ*(s)`，其中 γ = e^{−λh}；`r_gold` 由 GRM 自动判定，Φ* ≥ 1 − δ（δ = 0.05）即视为成功（§3.2.2）。

**理论（【事实】）。**
- 附录 A.2 证明：直接用 `Φ(s′) − Φ(s)` 作奖励，等价于最大化折扣后的进度累积，会诱导智能体停在高进度状态，即“semantic trap”。
- 附录 A.5 证明 PBRS 的不变性。推导假设无限时域（γ^T Φ(s_T) → 0），并把 Φ 当作只依赖状态的函数。

**实验（【事实】）。**
- **VOC。** 在 7 个数据集的留出轨迹上，8B 多视角版本在稀疏、中等、稠密三种采样下平均为 0.96 / 0.96 / 0.94；GVL 为 0.20 / 0.12 / 0.13，VLAC-2B 为 0.24 / 0.29 / 0.33（表 1）。
- **完成度判定。** 3 个任务、每个 60 条回放（成功、部分成功、失败各 20 条）：8B 多视角准确率 92.8%，GPT-5 为 83.9%，Gemini-2.5-Pro 为 81.1%，GVL 为 37.2%，VLAC 为 33.9%（表 2）。
- **策略学习（表 3）。**
  - 仿真（LIBERO-Goal，10 个任务）：BC 31.5%；PPO + 稀疏奖励 79.9%，用 560 个回合达到最终成功率的 80%；Dopamine-RL 81.0%，用 395 个回合。
  - 真机（8 个任务）：BC 9.8%；稀疏奖励的 ConRFT 68.0%，183 个回合；Dopamine-RL 95.2%，150 个回合。
- **泛化（表 4，3 个任务，每个 20 次）。** 在 OOD 条件下，BC 的相对下降为 50–60%，Dopamine-RL 为 8–20%。
- **消融（表 5，3 个真机任务）。** 完整版 85.0%；只用单一融合方式时下降 15.0–22.5 个百分点；去掉 PBRS 时下降 43.7 个百分点；去掉单示范适配时下降 21.8 个百分点。
- **真机设置（附录 C.3）。** ConRFT（Cal-QL 变体），Octo-Small 加一致性策略；离线阶段用 20–30 条示范；在线阶段有人工干预（HIL）；单张 RTX 4090。

**作者承认的局限（附录 E）。** VLM 推理延迟高；只用帧对推理、没有历史，存在状态歧义（例如分不清“抓取”与“释放”，处理不了循环类任务）；没有触觉和听觉；没有在动态任务上测试。

**方法缺陷**（empirical；read: arXiv 正文与附录 A–E）
- checked: found：variable operational definitions、internal validity、external validity、statistical reporting completeness | checked: none found：research hypothesis clarity | not checked：conclusion conservatism
- 进度标签是“各阶段等份额的时间”。当同一阶段内存在重试或停顿时，标签会把停留时间当成进度。后退标签来自专家轨迹的时间反转，与真实失败的视觉分布不同。[reader-inferred]
- `r_gold` 由 GRM 阈值判定，所以“不变性”只相对 GRM 的成功定义成立；如果 GRM 在终态判断出错，最优策略也会随之改变。[reader-inferred]
- 证明假设无限时域，Φ 只依赖状态；而保守更新（式 11）让 Φ 依赖历史，有限时域截断也没有处理。[reader-inferred]
- VOC 的评测集是训练所用数据集的留出轨迹，属于同域，而且都是专家轨迹。[author-acknowledged, section: 附录 C.1 评测协议]
- 真机主表（表 3、表 5）没有在正文中写明每个条件的试验次数。[reader-inferred，依据正文与附录 C.3 的检查]
- 仿真中的最终成功率与稀疏奖励 PPO 几乎相同（81.0% 对 79.9%），收益主要体现在所需回合数上。[reader-inferred，依据表 3]

**与 PRM4RL / RF-Agent 的关系。**
- 【事实】`r_gold + γΦ′ − Φ` 与 PRM4RL 的式 3 是同一形式。“直接用进度当奖励会偏离目标”这一点，PRM4RL 图 6 也有对应的现象。Robo-Dopamine 没有引用 PRM4RL。
- 【假设】两者的差别在于 Φ 的来源（VLM 与 LLM 程序）和成功信号的来源。对 TPAMI 论文来说，“PBRS + 进度”已不能作为新意。

### 2.2 ProcVLM（Feng et al., 2026，预印本）

**问题。** 时间不等于进度。以时间插值作标签，无法表达没完成的步骤、停滞和失败。

**方法（【事实】）。**
- **标注。** 用 Qwen3-VL-235B-A22B 做视频级的任务规划和子任务定位，再用 InternVL3.5-38B 做逐帧推理（附录 A.1）。
- **语料。** 30 个数据集，约 40 万条轨迹，6,000 万帧，构成 ProcCorpus-60M；由此生成 ProcVQA，约 20B token；精修阶段用约 1.5 万条人工挑选的轨迹，约 2.8B token（§3.1–3.2）。
- **进度标签（式 1）。** 每个子任务按时长分得进度预算，预算在“等份额”先验附近截断到 0.75–1.25 倍；子任务内部按相邻帧的感知差异分配进度。按这一构造，标签对时间单调不减。
- **模型。** Qwen3-VL-2B 加一个连续值回归头；推理时先生成剩余的原子动作，再估计进度；训练损失为语言建模损失加回归损失。

**实验（【事实】）。**
- **ProcVQA。** 进度 VOC 在同域为 0.8058（GPT-5.4 为 0.5229），在 OOD（未见过的 RoboTwin 任务）为 0.7282（GPT-5.4 为 0.6553）（表 1）。
- **与奖励模型的零样本比较（ProcVQA-OOD，打乱顺序的局部窗口）。** ProcVLM 0.7282，Robometer 0.5296，Robo-Dopamine-4B 0.7156。作者承认，给 Robo-Dopamine 输入时前置了一张空白图作为 BEFORE，这偏离了它的设计输入格式（表 2、附录 D.3）。
- **RoboFAC 真机子集。**
  - 零样本 VOC_succ：Robo-Dopamine-8B 0.9095，ProcVLM 0.4920，Robometer 0.4129。
  - 零样本 MCC：ProcVLM 0.6665，Robo-Dopamine 0.5506。
  - 给一条成功示范后，ProcVLM 的 VOC_succ 升到 0.9137、MCC 升到 0.7918；再加失败示范后为 0.9301 / 0.8053。
  - 单示范设置下没有报告 Robo-Dopamine 的结果（表 3）。
- **消融。** 去掉预训练后，失败定位误差（MAE_fail）增加 88.8%，MCC 下降 24.9%（表 4）。
- **RoboTwin 上的 GRPO（OpenVLA-OFT，2 个任务）。** Place Container Plate 上三种奖励模型相近，Robo-Dopamine 在收敛附近略高；Move Can Pot 上 ProcVLM 最高，Robometer 次之，Robo-Dopamine 两个变体接近 SFT（图 3）。所有奖励模型统一按以下方式接入：进度归一化，相邻差截断到 ±0.2，权重 1.0，环境成功奖励 0.1，γ 为 0.99 或 1.0（附录 F.1）。
- **真机（JAKA 叠碗，π0.5，Evo-RL 优势条件化训练）。** 软成功率，5k 步时 SFT 37.5、RFT 62.5，10k 步时 70.8 对 83.3；每种方法 12 次回放，只测了两碗场景（表 5、附录 F.2）。

**标注质量（【事实】，附录 G.1）。** 人工审计 92,465 条轨迹，要求整条轨迹的子任务描述和边界（1 秒内）全部正确，通过率 49.44%（DROID 33.44%，OXE 76.59%）。未通过的轨迹仍用于预训练。

**作者承认的局限。** 结果依赖子任务分解和边界定位的质量；回归头较轻，校准性留待改进；真机评测不够广（§5）。

**方法缺陷**（empirical；read: 正文全部，附录 A、D–G）
- checked: found：variable operational definitions、internal validity、external validity、statistical reporting completeness | checked: none found：research hypothesis clarity | not checked：conclusion conservatism
- 标签按视觉变化分配进度。重试抓取或来回调整会产生视觉变化但没有真实进度，这类片段会被计为进度；标签又单调不减，不包含倒退。[reader-inferred]
- 一半左右的自动标注至少有一处错误，却仍用于预训练。[author-acknowledged, section: 附录 G.1]
- 与 Robo-Dopamine 的比较使用了 Robo-Dopamine 原文所反对的接入方式（非 PBRS 的进度差），而且改变了它的输入格式。[author-acknowledged 输入格式, section: 附录 D.3; reader-inferred 接入方式, section: 附录 F.1]
- 真机每种方法 12 次，只测两碗场景，部分成功按半分计。[author-acknowledged, section: 附录 F.2]

**与 PRM4RL 的关系。**
- 【假设】ProcVLM 的“先推理剩余步骤、再估计进度”，相当于把 PRM4RL 中 LLM 一次写出的子任务结构交给 VLM 学习。它没有处理“进度如何接入 RL”这一 PRM4RL 的核心问题。

### 2.3 FLORA / Beyond Pixels（Xu et al., 2026，预印本）

**问题。** 视觉奖励模型会记住像素分布，泛化不到新的物体、位置和视角；LLM 写的奖励程序又依赖特权状态和大量在线交互。

**方法（【事实】）。**
- **Flow-Generator。** 每类任务在一张参考图上框出一次感兴趣区域（夹爪、物体、目标），可以人工框，也可以用 Grounding DINO。新回合开始时用 DINOv2 对应关系重新定位，再用 3D 点跟踪器 TAPIP3D 跟踪关键点，并转到以物体为中心的坐标系（§IV-A）。
- **符号势函数。** 输入当前和初始的运动流，输出势值和预测阶段。函数结构由 GPT-4.1 生成，内部参数由贝叶斯优化（UCB）调整。
- **PBRS-MS。** 记录已达到的最高里程碑 m_t（单调不减），定义里程碑势 Ψ(m)，奖励写成 `R′ = R + γϕ(s′) − ϕ(s) + γΨ(m′) − Ψ(m)`（式 2）。定理 1 证明增广 MDP 中最优策略不变，正文只给了证明梗概，完整证明在未包含于 arXiv PDF 的补充材料里。
- **离线双层优化。** 5 条示范按 60/40 分为训练集和验证集。代理目标 J 由三项组成：阶段预测与 GPT-4.1 标注的一致率；势值与时间的 Spearman 相关；非负塑形项所占比例（式 5–8）。全程不需要在线 RL。

**实验（【事实】）。**
- **MetaWorld 8 个任务（4 简单、4 多阶段）。** 每个任务 5 条脚本示范；测试集为 10 条成功轨迹、10 条部分成功轨迹、10 条随机轨迹。
  - 过程对齐（与时间的 Spearman）：FLORA 0.97，ReWiND-CT 0.89。
  - 回报排序：0.80 对 0.53；奖励差：0.80 对 0.16。
  - 三种 OOD（位置、视角、物体）下仍明显领先（表 I）。
  - 排序真值来自 MetaWorld 的人工稠密奖励。
- **策略学习（RLPD，3 个种子，IQM）。** 简单任务 96%，比最强基线高 22%；困难任务 42%，接近最强基线的两倍（图 7）。作者把“对齐指标高的方法学得更快”称为代理目标能预测 RL 表现（§VI-B）。
- **真机 Franka（RLPD）。** 奖励用 5 条示范；策略初始化前两个任务用 5 条示范，Bulb 用 20 条。
  - Box-Open 和 Peg-Insert：20 分钟时成功 20/20；ReWiND-CT 分别为 8/20 和 5/20，稀疏奖励为 0/20。
  - Bulb-Unscrew：60 分钟时 9/20，基线都是 0（表 II）。
  - Box-Open 的 OOD（30 分钟）：位置 20/20 与 19/20，视角约 45° 时 15/20，新物体 18/20 与 17/20；ReWiND-CT 多数为 0（表 III）。
- **消融。**
  - 把符号势换成 Transformer：ID 上过程对齐升到 0.99，回报排序却从 0.80 降到 0.60（表 IV）。
  - 标准 PBRS 在多阶段任务上不稳定，PBRS-MS 稳定（图 10）。
  - LLM 加 BO 的组合优于只用其一（表 V）。
  - 示范的空间覆盖缩小到 1/8 时，OOD 排序降到 0.17；5 条示范全是噪声时降到 0.13（表 VI）。

**作者承认的局限（§VII-C）。**
- 单调性假设：可逆子任务（例如插销卡住后要先退出）会受惩罚；多种合法顺序会被压制。
- 对遮挡敏感。
- 每类任务要人工指定一次感兴趣区域，约 1 分钟。
- 离线优化每个任务需要 1–8 小时。

**方法缺陷**（empirical；read: 正文全部，补充材料未取得）
- checked: found：internal validity、external validity、statistical reporting completeness | checked: none found：research hypothesis clarity、variable operational definitions | not checked：conclusion conservatism
- “势函数坍塌”的论证（§IV-C）基于有限时域 N 上的回报 `Σγ^t R_t + γ^N ϕ(s_N) − ϕ(s_0)`。里程碑之所以能让“快成功时掉落”的轨迹比“从未抓起”的轨迹回报更高，是因为截断时末端势项 γ^N Ψ(m_N) 保留了下来；而定理 1 的不变性需要末端势项消失或正确处理。所以两处论证的前提不同。[reader-inferred]
- “代理目标能预测 RL 表现”只基于 5 种方法之间的趋势，不是候选级别的留出预测。[reader-inferred，依据 §VI-B]
- 排序真值采用 MetaWorld 的人工稠密奖励，而这个奖励本身不是严格意义上的任务价值。[reader-inferred]
- 仿真只用 3 个种子；真机每个条件评估 20 次，正文没有说明训练重复了几次。[reader-inferred，依据 §VI-B、§VI-C]

**与 PRM4RL / RF-Agent 的关系。**
- 【事实】FLORA 的各个组成部分与 PRM4RL、RF-Agent 有直接对应：LLM 写符号势函数、阶段预测、PBRS 都和 PRM4RL 对应；用代理指标指导的结构搜索加参数优化，可以看作 RF-Agent 式搜索的离线版本。FLORA 没有引用这两篇。
- 【假设】它是方向 C 最直接的近邻。它自己承认的四项局限（单调性、遮挡、人工指定区域、离线成本），恰好对应方向 C 计划提供的增量。

### 2.4 ORSO（Zhang et al., ICLR 2025）

**方法（【事实】）。**
- 把“从 K 个候选塑形奖励中挑选”建模为在线模型选择问题，每个候选维护自己的策略。可选的选择算法有 ETC、ε-greedy、UCB、Exp3、D3RB（Algorithm 1）。
- D3RB 的遗憾界依赖 Assumption 4.2：存在一个学习器，在所有时刻累计期望回报都不低于其他学习器，并且平均回报单调增加。
- 实现上，每轮训练 n_iters/100 次迭代后重新选择；先用随机策略做拒绝采样，过滤掉产生 NaN 或 inf 的奖励；当某个候选训练满 n_iters，或所有候选的遗憾都过高时，重新采样候选集，一半由最优候选在上下文中演化，一半从头生成（附录 F，Algorithm 4）。

**实验（【事实】）。**
- **设置。** IsaacGym 6 个任务，PPO（CleanRL），GPT-4 生成候选；预算为 n_iters 的 5、10、15 倍；K 取 4、8、16；每个配置 3 个种子，每个任务共 27 次运行（§5.1–5.2）。
- **结果。**
  - 达到或超过人工奖励。
  - 最高预算下，归一化任务回报比朴素策略（Eureka 式，均匀训练每个候选）高 56%（图 2）。
  - “最多少用 8 倍 GPU”是按每次 PPO 迭代的耗时估算出来的近似值（图 3）。
  - 在 Ant 上用 K = 48 和 96 个候选（不重采样）时，D3RB 能选出有效的奖励；表 3 给出了全部 96 个候选的真实回报。
- **作者承认的局限（§7.1）。**
  - 带重采样时最多测试了 16 个候选，不带重采样时最多 96 个。
  - 依赖预先定义的任务奖励，难以处理带主观成分的任务（例如“好看的步态”）。
  - 没有研究并行化。

**方法缺陷**（empirical；read: 正文全部，附录 F–H）
- checked: found：internal validity、external validity | checked: none found：research hypothesis clarity、variable operational definitions、statistical reporting completeness | not checked：conclusion conservatism
- Assumption 4.2 排除了学习曲线交叉的情形，即先慢后快的优质奖励；而在长程稀疏任务中，这种情形可能正是常态。[reader-inferred]
- 加速倍数是按迭代耗时估算的，不是实际总时间。[author-acknowledged, section: §5.2]

**与 RF-Agent 的关系。**
- 【事实】ORSO 和 RF-Agent 解决的问题互补：ORSO 管“怎样在候选之间分配训练”，RF-Agent 管“怎样生成候选”。
- 【假设】ORSO 是方向 B 必须比较的强基线。如果候选都受 PBRS 约束，“学习曲线交叉”的程度可能会变小，因为所有候选的最优策略相同；这一点可以检验。

### 2.5 LaRes（Li et al., NeurIPS 2025）

**方法（【事实】）。**
- 维护 5 个由 LLM 生成的奖励，在“人工奖励初始化”设置下另加 1 个人工奖励；每个奖励对应一个 SAC 智能体。
- 所有智能体共用一个回放缓冲区。每条经验存下所有候选奖励的值，以及重标所需的变量。
- 用 Thompson 采样（按成功和失败次数更新）决定由哪个策略与环境交互。
- 每 20 万步（MetaWorld）或 50 万步（ManiSkill3）进化一次：按成功率选出最优奖励，由 LLM 反思后替换非精英个体（精英数为 3）；回放缓冲区按新奖励重标；非精英智能体从最优智能体的策略和 Q 函数继承参数；用奖励缩放（对齐均值和方差）和参数约束（与精英参数的 L2 距离）防止策略崩溃（§4、附录 B.2）。

**实验（【事实】）。**
- **设置。** MetaWorld 和运动任务训练 1M 步，ManiSkill3 和 MinAtar 训练 2M 步；5 次独立运行，报告 95% 置信区间。
- **有人工奖励初始化时。** 在 12 个 MetaWorld 任务上，优于用人工奖励的 SAC、多种进化 RL 方法，以及 Eureka、R*、Text2Reward（图 2）；在 ManiSkill3 的 4 个任务上优于 SAC（图 3）。
- **无初始化时。** 在 5 个 MetaWorld 任务上，样本效率更高（表 2）；Ant 和 Humanoid 在 1M 步时速度为 4.44 和 3.42，Eureka 为 1.49 和 2.02（表 3）。
- **公平性设置（附录 B.1）。** Eureka 被实现为“去掉持续学习和数据共享的 LaRes 变体”，进化轮数和种群规模相同。也就是说，在同样的总步数内，Eureka 的每个候选在每轮只能从零训练约 20 万步，而 Eureka 原文是让每个候选完整训练。
- **作者承认的局限（附录 A）。** 没有关于最优性、收敛性或复杂度的理论；进程通信带来约 20% 的额外时间；算力随策略数量线性增长；没有显式保证候选之间的多样性。

**方法缺陷**（empirical；read: 正文全部，附录 A、B、D）
- checked: found：internal validity、conclusion conservatism | checked: none found：research hypothesis clarity、variable operational definitions、statistical reporting completeness | not checked：external validity
- Eureka 和 R* 的基线被限制在同样的总环境步数内，每个候选的训练量远少于这些方法原文的设置，比较条件明显偏向 LaRes 的持续学习机制。[reader-inferred，依据附录 B.1]
- 奖励缩放和参数约束是经验性的稳定手段，作者没有说明它们在何种条件下成立。[author-acknowledged 无理论, section: 附录 A]

**与 RF-Agent / PRM4RL 的关系。**
- 【推导】LaRes 要处理“换了奖励，critic 就不再对应”的问题。假如它的候选都限制为同一稀疏奖励之上的 PBRS：
  - 继承策略不会产生不匹配，因为各势函数下的优势函数相同；
  - 但如果 critic 也精确平移，奖励进化就不再改变训练（§3.3）。

  所以在 PBRS 候选下，这个问题会消失，换奖励的作用也一起消失。这是 PRM4RL 定理 4.3（势函数塑形等价于 Q 值初始化）的直接推论。
- **更正：** 本条原先写的是“这个问题可以得到精确解”，没有指出精确解会让切换失去作用。

### 2.6 RoboReward（Lee et al., 2026，预印本）

**方法（【事实】）。**
- 输出回合结束时的离散进度分 1–5，评分标准是固定的 rubric。
- 训练数据来自 OXE（每个子数据集最多抽 1,200 条，全部是成功轨迹）和 RoboArena（含自然发生的成功和失败，有人工进度分）。
- 失败样本有两种合成方式：反事实改写指令（VLM 描述视频，LLM 提出“这段视频只算部分成功或失败”的替代指令，再由 VLM 验证）；把成功视频截断在较早的时间点（§4.1–4.2）。
- 训练、验证、测试按任务描述互不重叠，分别为 45,072、6,232、2,831 条。测试集逐条人工核验，构成 RoboRewardBench（§4.3）。

**实验（【事实】）。**
- **仿真（Robomimic，DSRL）。** 学到的进度奖励接近真值奖励的效果，学到的二值奖励明显更差（图 2）。准确率与 RL 表现相关，r = 0.83（图 3）。
- **基准（22 个 VLM）。** RoboReward-8B 的 MAE 为 0.665，GPT-5 mini 为 0.691，Gemini Robotics-ER 1.5 为 0.906（表 1）。
- **真机（WidowX，DSRL，2 个任务，各 20 次）。** 起始策略为 5% 和 10%；用人工奖励训练后为 75% 和 90%；用 RoboReward-8B 为 50% 和 80%；用 Gemini-ER 1.5 为 10% 和 45%（表 2）。
- **消融。** 去掉合成失败样本后 MAE 为 1.45，去掉截断样本后为 1.075，完整版为 0.845（表 3）。
- **作者承认的局限。** 主要面向短程任务；扩展到长程多阶段任务是未来工作（§6）。

**方法缺陷**（empirical；read: 正文全部，附录 B.4）
- checked: found：external validity | checked: none found：research hypothesis clarity、variable operational definitions、statistical reporting completeness | not checked：internal validity、conclusion conservatism
- r = 0.83 来自同一模型在不同训练阶段的检查点，在 3 个 Robomimic 任务上，属于同族比较。[reader-inferred]
- 奖励只在回合结束时给一次，不是逐步的稠密奖励，与其他几篇的进度势不是同一种用法。[author-acknowledged, section: §3]

### 2.7 SARM（Chen et al., ICLR 2026）

**方法（【事实】）。**
- 人工在顶视角视频上标注子任务的起止帧。按数据集平均计算各子任务的时长比例，作为它的进度份额；子任务内部按帧号线性插值（式 1–2）。
- 包含严重失误的轨迹不参与奖励模型训练。
- 冻结的 CLIP 编码器加关节状态，送入 Transformer；一个头分类阶段，一个头回归阶段内进度；采用 ReWiND 的“倒放帧”增强。
- RA-BC：用相邻窗口的进度差作为样本权重，权重区间按运行中的均值 ±2σ 确定（式 6–9）。

**实验（【事实】）。**
- **叠 T 恤，奖励模型评估。** 示范上的 MSE 为 0.009，ReWiND 为 0.019。在 36 条真机回放（成功、部分成功、失败各 12 条）上的分类分数 ρ：SARM 0.94，ReWiND 0.50（表 1）。
- **叠 T 恤，策略。** 用 200 小时示范和 π0；40k 步时，中等任务 10/12，困难任务 8/12；只用 BC（全部数据）为 1/12 和 0/12；用 ReWiND 的 RA-BC 为 6/12 和 3/12（表 3）。
- **RL。** 只有附录 A.8 的一个 MuJoCo 抓方块例子（DiffQL，每次评估 10 次回放）。

**方法缺陷**（empirical；read: 正文全部，附录 A.1–A.3、A.8）
- checked: found：external validity、statistical reporting completeness | checked: none found：research hypothesis clarity、variable operational definitions | not checked：internal validity、conclusion conservatism
- 主要用途是给行为克隆数据加权，在线 RL 的证据只有一个仿真小例子。[reader-inferred]
- 每个条件 12 次试验。[reader-inferred，依据表 1、表 3]

### 2.8 DenseReward（Fang et al., 2026，预印本）

**方法（【事实】）。**
- 在仿真中把操作分解为五个阶段：接近、抓取、抬起、移动、放置。阶段边界由仿真器状态自动判定。
- 通过定向扰动合成六类轨迹：成功、碰撞、抓空、掉落、动作不平滑、恢复。每类轨迹的奖励曲线形状是人为设计的，例如失败后呈“山峰形”衰减（§3.1–3.2）。
- 数据共 26,579 个回合，756 万帧，来自 DROID、Isaac、RoboSuite、LIBERO（附录 A）。
- 模型为 Qwen3-VL-4B，LoRA 秩 16，输入两帧历史。

**实验（【事实】）。**
- **离线 MAE。** DenseReward 0.081，RoboReward-8B 0.230，Robometer 0.366（表 1）。
- **MPC。** 评价指标只是末端执行器与物体之间的最小距离，即只测“接近”这一步（表 2）。
- **LIBERO 上的 PPO（π0）。** 奖励为稀疏成功奖励加上按 C/T_max 缩放的模型奖励；在 Spatial 和 LIBERO-10 上提高最终成功率，Object 上持平（图 5）。
- **真机（DROID 平台，DSRL，冻结 π0）。** 奖励为每步 −1 加模型奖励；每种方法 10 次试验；叠杯子从 40% 到 80%，球放进篮子从 30% 到 70%（图 6）。
- **消融。** 去掉失败数据后 MAE 从 0.0809 升到 0.1312；历史帧数为 0、1、2、3 时 MAE 分别为 0.096、0.088、0.081、0.086（表 3–4）。
- **作者承认的局限。** 只做了简单的抓放类任务，计划扩展到工具使用和长程任务。

**方法缺陷**（empirical；read: 正文全部，附录 A–E）
- checked: found：variable operational definitions、internal validity、statistical reporting completeness | checked: none found：research hypothesis clarity | not checked：external validity、conclusion conservatism
- 离线 MAE 的测试标签由同一套人为设计的曲线生成，对其他模型不公平：RoboReward 输出的是回合末的 1–5 分，尺度和含义都不同。[reader-inferred]
- 文中没有说明 DROID 真机回合的逐帧稠密标签是如何得到的；自动化流程依赖仿真状态，不适用于真机数据。[reader-inferred，依据 §3 与附录 A 的检查]
- 真机每个条件只有 10 次试验。[reader-inferred]

## 3. 跨论文对比与新的观察

### 3.1 “进度”的定义（【事实】，§2 各篇）

| 来源 | 进度的定义 | 失败与倒退怎么来 |
|---|---|---|
| PRM4RL | LLM 程序，基于特权状态的阶段判定加几何距离 | 由程序计算，可能下降 |
| SARM | 人工阶段 × 数据集平均份额 × 阶段内线性时间 | 排除失误轨迹，用倒放增强 |
| Robo-Dopamine | 人工关键帧分段，每段等份额 | 专家轨迹的时间反转 |
| ProcVLM | VLM 阶段（时长加权）× 阶段内视觉变化 | 标签本身单调，失败识别靠模型自行学到 |
| DenseReward | 仿真阶段，加上人为设计的失败曲线 | 仿真扰动 |
| RoboReward | 回合末 1–5 分 | 反事实指令和视频截断 |
| FLORA | LLM 符号势函数，按阶段一致性、单调性、正向塑形优化 | 由里程碑锁定已有进度 |

**【假设】** PBRS 理论给出的理想势函数是最优价值 V*（Ng 等 1999；Canonaco 等 2024，见综述 §2.3）。对于确定性的最优策略和稀疏的终止奖励，V*(s) 约等于 γ 的“最优剩余时间”次方，是剩余时间的指数函数；而表中各种进度大多与时间成线性关系，或者是按阶段分段的线性关系。这些进度语义作为势函数，在同一学习器和同一接入方式下效果相差多少，这 8 篇都没有回答。

### 3.2 接入 RL 的方式与“不变性”主张（【事实】）

- **PBRS 加稀疏成功：** PRM4RL（成功由环境给出），Robo-Dopamine（成功由奖励模型自己判定）。
- **PBRS 加里程碑 PBRS：** FLORA（增广状态，依赖有限时域末端项）。
- **非 PBRS：**
  - ProcVLM：截断的进度差，权重 1.0，加 0.1 倍成功奖励。
  - DenseReward：仿真中加性稠密奖励加成功奖励；真机上每步 −1 加模型奖励。
  - RoboReward：回合末给一次分。
  - SARM：用作 BC 的样本权重。

**【假设】** 由此产生一个混淆：比较奖励模型时，结果同时受“奖励模型质量”和“接入方式”影响。ProcVLM 在 RoboTwin 上对 Robo-Dopamine 的比较就是一个具体例子（§2.2）。

### 3.3 一个技术衔接点的核查：原先的设想不成立（2026-10-15 更正）

本节原先写的是：所有候选都是 PBRS 时，换势函数可以把 critic 精确平移，从而让多个势函数共享训练过程。核对原文并推导后，这个说法不成立。下面把依据、推导和剩下的可检验想法分开写。为此新读了三篇文献，读到的范围在各条中注明，原文存于 `_sources/added4_*`。

**【事实】恒等式本身是已知结果。**
- GAE 论文（Schulman et al., ICLR 2016）［原文：§4 全部］的式 (21)–(24)：对任意策略 π 和任意 Φ，塑形后 `Q̃^π = Q^π − Φ(s)`，`Ṽ^π = V^π − Φ(s)`，优势函数 `Ã^π = A^π` 完全不变；折扣塑形回报等于原回报减去 Φ(s_t)，相当于减去一个基线。
- Wiewiora（2003）证明：表格 Q 学习中加 PBRS，等价于不加塑形、但把 Q 初始化为 Φ。PRM4RL 定理 4.3 用的就是这个结果。Bahrpeyma（2026）［原文：§2.3–2.4、§5.4］复述了这个等价，并提醒它不能不加限定地推广到非线性函数逼近。

**【推导】精确平移会让切换失去作用。** 这是我自己的推导，需要你复核。

把 critic 写成“网络输出加解析偏置”。从 Φ₁ 换到 Φ₂ 时，令 `Q̃₂(s,a) = N_θ(s,a) + Φ₁(s) − Φ₂(s)`，目标网络也同样处理。代入 Φ₂ 下的 TD 误差：

`r + γΦ₂(s′) − Φ₂(s) + γQ̃₂(s′,a′) − Q̃₂(s,a) = r + γΦ₁(s′) − Φ₁(s) + γN_θ̄(s′,a′) − N_θ(s,a)`

右边正好是继续用 Φ₁ 时网络看到的 TD 误差。偏置与动作无关，所以 SAC 的策略更新和 PPO 的 GAE 优势也都不变。

结论：无论用什么函数逼近器，平移之后的训练都与不换势函数完全相同。前提是两条：超时截断处正确自举；不做会改变塑形项尺度的奖励或价值归一化。这是 Wiewiora 等价的直接推论，很可能已经有人指出过，不能作为贡献。

由此得到三点：
1. 本文件 §1 第 6 条（b）、§2.5 末条、§4 方向 A 和 §5 第 1 条中的相关说法都已更正。精确平移不能让多个势函数共享训练，因为平移之后，新势函数不再起任何作用。
2. 对 PBRS 候选，势函数对学习过程的影响只来自三处：
   - critic 的隐含初始值（等价于把价值初始化为 Φ），以及网络拟合残差 `Q^π − Φ` 时的归纳偏置；
   - GAE 在 λ < 1 时的偏差；
   - 有限时域截断处理不一致时留下的末端项。
3. 用在 LaRes 式“换奖励但继承智能体参数”的做法上，如果候选都限制为 PBRS：
   - 继承策略不会产生不匹配，因为各势函数下的优势函数相同；
   - 如果 critic 也精确平移，奖励进化就不再改变训练；
   - 如果不平移，继承下来的 critic 相当于把 `Φ_new − Φ_old` 注入了隐含的价值估计，也就是做了一次动态 PBRS（Devlin & Kudenko 2012 的结果，经 Bahrpeyma 定理 2 复述）。

**【事实】在同一批经验上同时学习多个势函数，已有前人工作。**
- Harutyunyan 等（2015，ALA 2015，短版见 AAMAS 2015）［原文：§1–5.1 全部，§5.2 部分，§6 未读］。
  - 动机正是“事先不知道哪个启发式有效，逐个测试要额外的样本”。
  - 做法：用 Horde 架构维护一组 Greedy-GQ(λ) 学习器，每个学习器对应一个势函数和一个缩放系数。行为策略固定为均匀随机，所有学习器从同一条经验流离策略学习，最后用投票合成目标策略。
  - 结果：在 Mountain Car 和 Cart-Pole（tile coding 线性逼近）上，集成策略与最好的单个势函数在统计上相当，或者优于所有成员；在宽范围缩放系数上做集成，效果与调好系数的集成相当。
- LaRes（§2.5）在深度 RL 中让多个候选奖励共享回放缓冲区，并按各自的奖励重标。
- 所以“多个候选共享经验”本身不是新想法。如果要做，增量必须超出这两项工作。

**【假设】剩下的一个可检验想法（可用于方向 B）。**
- **想法。** PBRS 候选的作用等价于给价值函数一个初始值，那么候选势函数在有限预算内的效用，也许可以用一个廉价量来预测：Φ 与学习过程中会遇到的策略价值 V^π 有多接近。例如，用当前最好策略或示范的回放估计 V^π，再计算 Φ 对它的拟合程度。
- **依据。** Ng 等（1999）指出 Φ = V* 最理想。GAE §4 指出，Φ = V^π 时响应函数只在当前步非零，信用分配的时间跨度最短。
- **怎么检验。** 可以直接用方向 B 的 E-B1 数据。如果这个拟合度预测效用并不比 LLM 自评或短训回报更好，就推翻这个想法。
- **新颖性。** 还需要核对，至少要比较三项工作：
  - BSRS（Adamczyk et al., AAAI 2025）［摘要］，用智能体当前的价值估计作为势函数；
  - Müller & Kudenko（2025）［笔记；Bahrpeyma §5.4 转述其结论：势函数加常数偏置会明显影响深度 RL 的性能］；
  - Canonaco 等（2024）［摘要］。

**另一个具体空白。**
- 【事实】Bahrpeyma（2026）§5.4 比较了回放缓冲中处理时变势函数的四种做法：随经验存下当时的势函数值；采样时按当前势函数重算；按轮次冻结势函数并清空缓冲；限制势函数的变化速度。它指出四种做法各有代价，而且“所综述的文献中没有找到隔离这些取舍的对照研究”。
- 【假设】方向 A 的 A3（c）可以回应这个空白。

### 3.4 选择信号与评价协议（【事实】）

- ORSO 和 LaRes 都用真实任务成功作为选择信号。在真实机器人上，这个信号要么来自奖励模型（Robo-Dopamine 的 `r_gold`），要么来自人。
- 真机试验次数：10 次（DenseReward）、12 次（ProcVLM、SARM）、20 次（RoboReward、FLORA）。
- 离线指标各不相同：VOC、MAE、成功/部分成功/失败三分类、过程对齐。

**【假设】** 在这样的样本量下，奖励模型之间 10–20 个百分点的差距很难达到统计上可分辨的程度。TPAMI 论文需要更大的评测规模，或者采用配对设计。

## 4. 对三个候选方向的影响

**方向 A（规格与塑形分离）**
- **【事实】更强的支持。**
  - Robo-Dopamine 的消融显示，去掉 PBRS 后真机成功率下降 43.7 个百分点。
  - FLORA 和 VLM-PBRS 都采用 PBRS。
  - 不同论文的接入方式混乱，不变性主张的前提各不相同（§3.2）。
- **【事实】更大的新颖性压力。**
  - “PBRS 加进度势”已被 CVPR 2026（Robo-Dopamine）和 FLORA 采用。
  - “把 LLM 限制在 PBRS 空间里搜索”已有 LLM-ALSO（见综述）。
- **【假设】可以补充的增量：**
  - §3.3 的推导：PBRS 候选的作用等价于价值初始化，精确平移 critic 后切换不起作用。它可以回答 A3（c）“热启动时更换势函数”会怎样，但它是已知结果的推论，不能单独作为贡献。原先写的“使受 PBRS 约束的搜索可以共享训练过程”已撤回。
  - Bahrpeyma（2026）§5.4 指出的空白：回放缓冲中处理时变势函数的几种做法，还没有对照研究（§3.3 末段）。
  - 系统处理“不变性相对于谁的成功定义”这一问题，Robo-Dopamine 的成功由自身判定就是一个反例。
  - 系统处理有限时域截断（FLORA 的里程碑恰好依赖这一点）。

**方向 B（有限预算效用）**
- **【事实】** ORSO 的遗憾保证排除了学习曲线交叉；LaRes 的比较条件偏向自身；两者都不预测效用，都依赖任务成功作为选择信号。
- **【假设】** B 可以具体化为“进度语义 × 接入方式”的受控比较（§3.1–3.2）。候选包括已公开的学习型模型（RoboReward，Robo-Dopamine GRM 2.0 的 4B 版本，ProcVLM 在比较中已使用）和程序化进度（PRM4RL、FLORA 式）。在同一学习器和同一预算下，测量哪种语义、哪种接入在有限预算内效用最高，并检验离线指标（VOC、MAE）能否预测这一排序。这个问题比“通用效用预测”更具体，也更贴近你的两篇工作。
- **【假设】** §3.3 的“Φ 与策略价值的拟合度”可以作为 E-B1 中的一个候选预测量，与 LLM 自评、短训回报并列比较。
- **【待你决定】** 各模型权重是否公开需要逐个确认。

**方向 C（真实观测下可辨识的进度）**
- **【事实】** FLORA 自己承认的四项局限（单调性或可逆子任务、遮挡、人工指定区域、离线成本）与方向 C 的计划增量一一对应。Robo-Dopamine 和 DenseReward 表明，多视角和历史帧对判断有帮助，并且已经有真机 RL 收益，因此方向 C 的基线必须包括 FLORA 式方法，以及至少一种可用的学习型模型。
- **【假设】** 方向 C 的核心不应是“再训练一个进度模型”，而应是“在遮挡和不可逆情况下，程序化进度怎样借助信念和主动观测保持可辨识”。这一点与上述论文都没有重叠。
