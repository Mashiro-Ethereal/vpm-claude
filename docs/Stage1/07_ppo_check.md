## 3. 接入本身【事实】

- PBRS 包装套在 `ManiSkillVectorEnv` 里面，每步奖励按 R = γΦ(s′) − Φ(s) + 成功 × r_bonus 计算（M5 的冒烟测试已逐项核对），训练中的平均奖励约 −0.025，与 −0.2 × 平均 Φ 相符。
- teacher 每步的阶段、Φ、塑形项都正常记录；部分重置、自动重置都没有出错；训练速度约 11,500 步/秒，稠密奖励约 12,500 步/秒，慢约 8%，与 M5 测的开销相当。
- 所以“能不能接入”的答案是能；问题在“接进来之后能不能学”。

## 4. 分析【推导】

1. **γ = 0.8 下，PBRS 的塑形项对停留有惩罚，而且随 Φ 增大。** 不动时塑形项是 γΦ − Φ = −0.2Φ。在 grasp 段（Φ ≈ 0.25）每停一步扣约 0.05；抓住后进入 carry（Φ ≈ 0.5），每停一步扣约 0.1。抓住那一步虽然有约 +0.15 的跳变，但之后如果不能很快把方块送到目标，扣分会把它抵掉。训练前期随机抓住过方块，之后 carry 降到 0，和这个机制一致：策略学会了不去抓。
2. **PBRS 不改变最优策略，所以等于在学 γ = 0.8 下的稀疏任务。** 成功要十几到几十步，0.8 的 20 次方约 0.01，从起点几乎看不到成功奖励。PBRS 理论上只帮 critic 估值，不改变优势函数的期望；γ 这么小时，稀疏任务本身就学不动。
3. **ManiSkill 的稠密奖励不是势函数形式**：每一步都按到方块的距离、是否抓住、到目标的距离给正奖励，改变了问题本身，所以在 γ = 0.8 下也能学。官方的 γ = 0.8 是为这种奖励调的。
4. **次要因素：** grasp 段的守卫是布尔的，按设计不写 progress（01 §4.2），`near` 的阈值又宽（离方块中心 5.5 cm 内就进入 grasp），所以“靠近到能抓”这一段没有任何塑形。γ 小时，这一段的探索更难。
5. 这些都还是推断。最直接的检验是把 γ 调高：PBRS 要求塑形的 γ 与 RL 的 γ 相同（§3.3 第 1 条），所以两者一起改成 0.99；同时用稠密奖励、稀疏奖励在 γ = 0.99 下各跑一次作对照。若 teacher 在 γ = 0.99 下学会，而稀疏奖励学不会，说明 teacher 的塑形确实有用，问题在 γ；若仍学不会，就要考虑 grasp 段的塑形，或奖励的形式（会涉及整体设计，届时记入 01 §5 与你讨论）。

## 6. 第二次分析【推导】

1. **γ 不是主因。** γ = 0.99 时停留的惩罚只有 −0.01Φ，teacher 仍然学不会，而且比 γ = 0.8 时退化得更彻底（从 grasp 退回 reach、再远离方块）。第 4 节第 1 条的机制最多是次要因素。
2. **更可能的原因：critic 学准之后，PBRS 对策略梯度没有额外信号。** 若 critic 学到 V(s) = V_稀疏(s) − Φ(s)，每一步的 TD 误差与只用稀疏奖励时完全相同，GAE 优势也相同；在从未成功的情况下，优势就是 0。换句话说，对 PPO 这类策略梯度方法，PBRS 在期望上相当于一个基线，只在 critic 还没学准的前期起作用。这与观测吻合：前 100 万步内 critic 还不准，策略被势差推着靠近、甚至抓住方块；critic 很快学准（1024 个并行环境，解释方差到 1.000），塑形信号消失，又没在这之前碰到真正的成功，策略随噪声漂移、熵塌缩，退化成远离方块。
3. **与 PRM4RL 的差别。** PRM4RL 用同一个公式，在 ManiSkill 上有效【事实，读书笔记 `references/notes/base_progress_reward.md`】。差别有三：(a) Φ 是“阶段编号 + 阶段内进度”，范围 [0, K]，没有除以 K，塑形的幅度是这里的 K 倍；(b) 策略的输入拼了当前阶段的语言嵌入；(c) 用的是 SAC（γ = 0.99），或只有 8 个并行环境的 PPO（γ = 0.8，批量 400）。SAC 的 critic 是 Q 函数，PBRS 等价于 Q 的初始化（PRM4RL 附录 A.1）；并行环境少时 critic 学得慢，势差信号持续得更久。哪一条起决定作用，现在还分不清。
4. **这是“teacher 怎样做奖励”的问题，属于 Stage2 与整体设计（VPM_idea §3.3），不是 Stage1 的生成问题。** Stage1 交付的 teacher 能接入、能正常给出阶段和 Φ；它做奖励时用什么算法、Φ 取什么尺度、策略要不要看到阶段，要讨论后再定。已记入 01 §5。
