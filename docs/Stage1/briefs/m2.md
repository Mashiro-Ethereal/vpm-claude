4. vpmkit/adapters/maniskill/adapter.py: `ManiSkillAdapter(env, bind)`
   - `env` is a gymnasium env (wrappers allowed); the task object is `env.unwrapped`. The constructor calls `bind(env.unwrapped, api)` once. The result must be a dict from string keys to specs, with at most one gripper.
   - `snapshot(info=None) -> vpmkit.world.Snapshot`, valid after the environment has been reset. It reads every binding at the current state. All tensors are cloned (never alias simulator buffers), live on `env.unwrapped.device`, and are float32 (bool for grasping).
     - Gripper. Support the Panda family only (robot uids "panda" and "panda_wristcam"; any other robot raises NotImplementedError naming it). pose = `agent.tcp.pose.raw_pose` (link panda_hand_tcp); lin_vel / ang_vel = the TCP link's linear_velocity / angular_velocity; width = the sum of the two finger joint positions (`robot.get_qpos()[:, -2:].sum(-1)`); max_width = the sum of the two finger joints' upper limits (from `robot.get_qlimits()`); arm_qvel = `robot.get_qvel()[:, :-2]` (the slice Panda.is_static uses); half_size None.
     - Actor. pose = `actor.pose.raw_pose`, always through `Actor.pose`: on the GPU, ManiSkill hides objects listed in `_hidden_objects` (PickCube's goal_site) by moving them far away while rendering, and `Actor.pose` returns the true pose; never read the raw physx buffers. lin_vel / ang_vel = `actor.linear_velocity` / `actor.angular_velocity`. half_size normalized to [N, 3].
     - Site. pose from its callable (a Pose becomes raw_pose); lin_vel = ang_vel = zeros; half_size normalized.
     - attrs: callables are called with env.unwrapped at every snapshot; values are broadcast to [N, ...]; a Pose becomes raw_pose; numbers become float32.
     - grasping: for every actor binding, `agent.is_grasping(actor)` with its default arguments. For an actor without collision shapes (`Actor.has_collision_shapes` is False), all False without calling is_grasping. Sites and the gripper get no grasp entry.
     - contact_force: for every unordered pair among the gripper and the actor bindings, a magnitude in newtons. Actor-actor: the norm of `scene.get_pairwise_contact_forces(a, b)`. Gripper-actor: |F(agent.finger1_link, actor)| + |F(agent.finger2_link, actor)|. A pair involving an actor without collision shapes: zeros, without querying. Sites get no entries.
     - table_z: zeros [N]. ManiSkill's TableSceneBuilder places the table top at z = 0 (the ground is built at altitude -table_height); confirm it in the integration test from the table actor and state the evidence in your report.
     - official: the keys returned by `env.unwrapped.evaluate()`, determined once on the first snapshot. If `info` is given, take those keys from it; otherwise call `env.unwrapped.evaluate()`. Nothing else (no elapsed_steps).
   - Errors raised by `bind` or while reading a binding (including the user callables) are wrapped into a new `vpmkit.errors.BindingError(CandidateError)` that names the binding key (or "bind") and chains the original exception. The later run check reports it as run.bind.
