Definitions (00 section 4.6):
- Reward R = gamma * Phi(s') - Phi(s) + 1[success(s')] * r_bonus, with gamma equal to the RL algorithm's discount (ManiSkill's PPO uses 0.8). The environment's own reward is not used.
- On a successful termination (terminated is True), Phi(s') is taken as 0. A time-limit truncation is not a termination: Phi(s') is used as computed, and the RL algorithm bootstraps from the critic.
- Phi is computed exactly once per state and reused, so that the shaping terms telescope over an episode.
- The wrapper wraps the ManiSkill environment and sits inside ManiSkillVectorEnv, at the level of the official PPO's FlattenActionSpaceWrapper: ManiSkillVectorEnv resets finished environments inside its step() and returns post-reset observations, so outside it Phi(s') of a truncation step would be computed on the reset state.

Create:
1. Teacher.step(snapshot, env_mask=None) in vpmkit/teacher.py: with a bool [N] env_mask, only the masked environments' stage and invariant counters are updated; the others keep theirs. The outputs are still returned for all environments, computed from each environment's resulting stage. Without env_mask, behavior is unchanged (all existing tests must pass).
2. vpmkit/rewards/__init__.py, vpmkit/rewards/pbrs.py: `PBRSWrapper(gymnasium.Wrapper)`:
   - __init__(env, candidate, gamma, r_bonus, params=None): builds a ManiSkillAdapter(env, candidate.bind) and a Teacher(candidate, num_envs, device, params) for env.unwrapped.
   - reset(seed=None, options=None): calls env.reset; if options has "env_idx" (a partial reset, as ManiSkillVectorEnv issues), resets the teacher for those environments and steps it with env_mask on the new snapshot, storing their Phi; otherwise resets and steps all. Returns obs and info unchanged.
   - step(action): calls env.step; snapshot(info); out = teacher.step(snapshot); phi_next = out["phi"]; phi_used = where(terminated, 0, phi_next); reward = gamma * phi_used - phi_prev + success * r_bonus (success from info["success"]); then phi_prev = phi_next for every environment (finished ones get overwritten by the partial reset that follows). Adds info["pbrs"] = {"phi": phi_next, "phi_prev": the old phi_prev, "phi_used": phi_used, "stage": out["stage"], "shaping": gamma * phi_used - phi_prev, "elapsed_steps": info["elapsed_steps"] at the time Phi was computed}. Returns the shaped reward as a float32 [N] tensor on the env device.
   - Everything batched on the env device, no per-environment loops.
3. configs/default.yaml: add a section `pbrs: {gamma: 0.8, r_bonus: 1.0}` (gamma is the discount of ManiSkill's PPO; r_bonus is a placeholder that the orchestrator will set). Keep the existing sections unchanged.
4. scripts/pbrs_smoke.py: the smoke test below as a script that prints a short summary; gamma and r_bonus default to the values in configs/default.yaml (overridable with --gamma and --r-bonus).
