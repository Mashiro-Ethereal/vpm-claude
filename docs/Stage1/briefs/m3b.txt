<spec>
General rules for every candidate (these are the rules the generating agent will also follow):
- Predicates receive objects only as parameters, read only the WorldView / ObjView API, never official/evaluate entries, never object names. Thresholds are keyword-only defaults. Each predicate has a one-sentence `desc` that states exactly what it computes, English `need_true` / `need_false` templates (`need_false` whenever the predicate is used negated), and a sensible `scale` (meters for distances).
- Where a predicate copies an evaluate() formula, copy it EXACTLY (same reference points, same constants, same inequalities up to >= vs > at the boundary), using object parameters instead of env fields (e.g. the cube half size comes from the bound object's half_size, a goal radius from an attr of the bound goal object). Such predicates' thresholds must NOT appear in `params`, and the correspondence goes into the `official` block.
- Regression targets: a broken "grasped" invariant regresses to the grasp stage (not to the reach stage, whose guard needs an open gripper).
- Every stage gets a progress function unless the default (mean of literal satisfactions) is adequate; progress uses fixed scale parameters declared in `params` with ranges (names `progress.<stage>.<param>`), never episode-initial snapshots.
- bindings.py: `bind(env, api)` where env is the unwrapped ManiSkill env.
- notes.md: 5–15 lines: stage rationale, which predicates copy official formulas, known quirks of the official judgments.

Shared predicate definitions (re-define them in each candidate's predicates.py; candidates do not share code):
- gripper_open(g, *, w=0.07): g.width - w.
- near(g, o, *, d=0.02): d - dist(g.pos, o.pos).
- grasped(g, o): w.bool_margin(w.grasping(g, o))  (same function ManiSkill's evaluate uses).
- lifted(o, *, h=0.02): obb_min_z(o) - h.
- static(o) (official Actor.is_static(lin_thresh=1e-2, ang_thresh=0.5) as used by the tasks): min(0.01 - |linvel|, 0.5 - |angvel|).
- arm_static(g, *, v=0.2) (official agent.is_static(0.2): max |arm joint velocity| <= 0.2): v - max(|g.arm_qvel|).

   predicates: gripper_open, near, grasped, at_goal(o, t, *, r=0.025) = r - dist(o.pos, t.pos) (copies is_obj_placed with goal_thresh 0.025), arm_static.
   stages: reach [gripper_open(g), near(g, cube)]; grasp [grasped(g, cube)]; carry [at_goal(cube, goal)] with invariant grasped(g, cube) -> grasp, event "{cube} slipped out of {g}."; settle [arm_static(g)] with invariant at_goal(cube, goal) -> carry, event "{cube} moved away from {goal}.".
   official: [grasped(g, cube)] -> is_grasped; [at_goal(cube, goal)] -> is_obj_placed; [arm_static(g)] -> is_robot_static; [at_goal(cube, goal), arm_static(g)] -> success.
   params: gripper_open.w (0.07, [0.05, 0.078]), near.d (0.02, [0.01, 0.05]), and progress scales (reach: distance gripper-cube over d0 = 0.3; carry: distance cube-goal over d0 = 0.3).

6. Example: PushCube-v1 (cube = env.obj with half size env.cube_half_size; goal marker env.goal_region, a kinematic disk with radius env.goal_radius; success = xy distance cube-goal < goal_radius and cube z < cube_half_size + 0.005).
