# Training Robots to Evaluate Robots: Example-Based Interactive Reward Functions for Policy Learning

Huang, Hu, Jayaraman；CoRL 2022，PMLR 205 正式出版于 2023。补充检索，2026-10-06。

- 来源：[正式记录](https://proceedings.mlr.press/v205/huang23a.html)、[论文](https://proceedings.mlr.press/v205/huang23a/huang23a.pdf)、[补充材料](https://proceedings.mlr.press/v205/huang23a/huang23a-supp.pdf)。保存正文 PDF/文本。
- 实际阅读：正文 §1–6 全部方法和实验；补充 A.1–A.9 的算法、观测/动作定义、对照、重试和全可观测消融；A.10 未细读。
- 问题：成功和失败在被动观测中相同，怎样获得可用于 RL 的奖励。
- 方法：先用 VICE 学初始任务策略，提供可交互的成功物理配置，并用初始策略生成负例；训练验证策略，使其交互后的观测能区分正负初始状态；终局加入验证奖励。部署时执行固定长度任务策略后验证，失败则重试。
- 监督和假设：成功配置必须可实际呈现/重置；初始策略输出主要作为负例，适用于被动奖励经常误判的任务。验证动作允许改变环境，可能破坏样例。该代价真实存在：积木实验需约 7k 个可交互正例，而旋紧任务可反复用 1 个。
- 实验证据：门锁、不同重量积木为仿真，旋紧为真实 DClaw。仿真 5 seeds；任务训练约 2M steps，实机约 50k steps/10h，验证策略约 20k steps。Table 1 的 LIRF→LIRF+Verify 成功率门锁 0.640→0.958、堆叠 0.846→0.884、旋紧 0.82→0.99。补充 A.8 另比较相同额外时长与真值成功检查，因此不能把全部收益归因于无对照的重试次数。
- 观测边界：实验输入是模拟完美视觉的混叠角度、物体位姿等，包括实机混叠阀角和关节角；并非从原始 RGB 学会这些验证。验证时机采用固定执行—验证循环，没有优化跨阶段的验证预算。
- 对本项目的判断：直接否定“首次让奖励函数主动交互/验证/重试”的新颖性。仍可检验的增量是：从原始视觉学习可迁移的阶段验证，依据验证改变后续决策的价值与代价选择时机，并在同总操作预算下优于固定验证和不确定性阈值。这个增量是否足够，须由实验决定。
