# On Learning Intrinsic Rewards for Policy Gradient Methods

Zheng, Oh, Singh；NeurIPS 2018。补充检索，2026-10-06。

- 来源：[正式论文](https://proceedings.neurips.cc/paper_files/paper/2018/file/51de85ddd068f0bc787691d356176df9-Paper.pdf)。已保存 PDF 和文本。
- 实际阅读：摘要、§2 相关工作、§3 方法全文和算法、§4 实验设置；未精读全部结果与补充实验。
- 问题与方法：内在奖励应帮助受计算、数据和表示限制的学习器提高外在目标，而不是被当作最终目标。LIRPG 对策略更新求元梯度，内层优化外在＋内在奖励，外层按更新后策略的外在收益训练奖励模型。复用轨迹时使用重要性修正。
- 依据：论文应用到 Atari/A2C 与 MuJoCo/PPO，摘要明确称多数而非全部任务改善；读取设置包含仅外在奖励、存活奖励和计数探索对照。
- 假设与边界：需要外在收益和可微策略学习；§3 的推导/近似不等于任何短程指标必然预测最终学习效果。此处没有跨奖励家族的离线选优结果。
- 对本项目的判断：按真实学习收益评价/更新奖励、区分目标奖励与学习奖励都不是新概念。RF-Agent 延伸的价值应落实到在视觉奖励家族/任务/优化器迁移时节省多少试验成本，以及何种低成本证据确实预测选优结果。
