# Dynamical Distance Learning for Semi-Supervised and Unsupervised Skill Discovery

Hartikainen, Geng, Haarnoja, Levine；ICLR 2020。补充检索，2026-10-06。

- 来源：[论文](https://arxiv.org/pdf/1907.08225)、[作者项目](https://sites.google.com/view/dynamical-distance-learning)。保存了 PDF 和文本。
- 实际阅读：摘要、§3–5 方法全文、§6 实验设置和 6.1–6.2、附录 B 定理条件；未逐项复核全部附录实验。
- 问题：如何从交互学习符合动力学的目标距离，替代手写距离奖励，并用很少偏好确定目标。
- 方法：从同轨迹状态对回归时间差，得到策略条件距离；交替学习距离、选目标和用负距离奖励训练 SAC。距离依赖当前策略，距离更新使用近期经验。
- 关键假设：同一轨迹采样隐含成功到达条件，有限轨迹造成截断偏差。§4.3 已明确指出“成功条件下距离短”不等于“到达概率高”，给出风险短路例子；作者用沿途累计距离而非贪心最小距离处理。附录 B 的策略改进结论依赖确定性动力学，不能直接推广成任意随机环境的成功概率保证。
- 实验证据：真实 DClaw 旋阀、视觉和状态输入，10 次偏好查询，约 8 小时；仿真操纵和运动控制。视觉为 32×32 RGB，比较 SAC 真奖励和 VICE，结果支持所测单目标技能上的效率。
- 边界：不提供通用语言任务状态、分支恢复识别或跨任务校准概率；但“学习可控的视觉距离”“把时间距离作为奖励”已是旧问题。
- 对本项目的判断：PRM4RL 后续若改为剩余时间或可达性，必须把 DDL 和 RCE 纳入比较。不能把 DDL 描述成未意识到成功轨迹偏差的时间回归方法。新增研究需要明确新增观测/任务语义与跨分布证据。
