# 本次研究分析的阅读约定

研究日期：2026-10-06。目标：以用户两篇已发表工作为基础，形成面向 IEEE TPAMI 的三个候选研究问题及可证伪的最小实验；方向尚未由用户选定。

## 方法与顺序

采用 ARS-Codex deep-research 中的两轮筛选、WHY/HOW/WHAT 提取、主题综合、相互挑战的证据对照，以及具体可检验问题的收敛方法。用户明确要求先阅读基础论文，再筛选全部参考文献，最后提出方向，因此不使用先提问选定研究问题才能检索的默认流程。无需论文写作、实验执行或研究方向评分。

1. 两篇基础论文由不同子智能体分别阅读正文、方法、实验与必要附录，主智能体综合其关系。
2. 对 sources.csv 的全部 150 条目尝试获取摘要或正文。文献表及既有分类用于定位来源，不作为方法与结论的证据。两篇基础论文也包含在这 150 条内，不重复计数。
3. 根据实际阅读得到的研究问题、方法与证据划分主题，精读最接近、基础性及可能推翻候选判断的论文；按出现的问题补充检索。
4. 主智能体独立综合，提出三项研究问题、最小验证、比较对象、资源与 TPAMI 契合度。

所有委派均使用 gpt-6.1-sol，reasoning_effort=high。主智能体保留综合判断责任。

## 每篇笔记记录内容

- 引用键、标题、年份与来源链接；预印本和已发表版本分别注明。
- 实际读取的来源与范围：摘要初筛 / 选择性精读（具体节、表、附录）/ 全文阅读 / 获取受限。
- 问题、方法、监督和输入条件、主要证据、适用边界、与基础论文及研究问题的关联。
- 原文结果与阅读者推断明确区分；摘要报告的数字不得写成已核对实验细节。
- 获取失败记录尝试地址和障碍，不据此断言论文不存在，也不从题目补造内容。

原始文献留在原处。必要抽取和来源片段放在 `_sources/`。本地PDF页码若未获ARS预检确认，优先使用正文节、公式、表图编号。跨论文实验若数据、策略、监督预算或计算预算不同，不直接比较成功率大小。

## 补充检索边界

以原始论文、作者项目页、正式会议论文集和IEEE期刊页面为依据。检索覆盖基础理论及截至本次日期能够取得的近期相关工作，保留关键查询与来源。无全文的最新工作仅用于指出可能的竞争与待核实事项。此处是定向研究综述，不声称完成所有数据库的系统综述。
