# TPAMI范围与选题判断依据

核对日：2026-10-06。

**官方范围。** [IEEE Computer Society征稿页](https://www.computer.org/digital-library/journals/tp/cfp-ieee-pattern-analysis-machine-intelligence)说明，TPAMI涵盖计算机视觉、图像理解、模式分析与识别及部分机器智能领域，强调面向模式分析的机器学习。该页的官方检索记录可读，直接打开曾返回内部错误；未据非官方影响因子或接收率判断。

**实际发表实例。** [CA-Nav](added_chen2025_canav.md)表明结构化的视觉语言任务理解与闭环决策属于其发表实践；[Klink等的课程RL研究](added_klink2024_curriculum_ot.md)说明一般RL的明确方法问题也可在该刊发表。后者有作者接受稿、机构出版记录与开放代码相互支持。

**研究判断。** 视觉过程表征、任务状态可辨识性、奖励评价如何预测学习行为，都可与该刊范围建立实质联系。纯粹把已有搜索框架换一个LLM、增加提示词或在同一套低层任务上获得小幅收益，其期刊论证较弱。所提工作的贡献必须能从问题定义、方法机制、必要对照和可复现证据中看出来。此判断是对选题契合度的分析，不是编辑标准的逐项保证。
