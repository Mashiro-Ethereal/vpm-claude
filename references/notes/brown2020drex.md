# Better-than-Demonstrator Imitation Learning via Automatically-Ranked Demonstrations

引用键：brown2020drex。阅读日期：2026-10-06。

- 来源：[实际读取原始来源](https://proceedings.mlr.press/v100/brown20a.html)。
- 版本、发表状态与实际范围：摘要，正式CoRL2019/PMLR2020。书目所列年份：2020；venue：CoRL 2019 / PMLR 100 (2020)（除明确写已核验者，书目状态不视为独立确认）。
- WHY：偏好排序难取得。。
- HOW：BC策略加噪自动造排序示范并学奖励。。
- WHAT：优于示范的充分条件及模拟验证。。
- 假设、监督与输入：示范；噪声与性能关系。。
- 验证依据：Atari与模拟机器人。。
- 边界：自动排序的正确性依干扰规律。。
- 关联（阅读者推断）：失败轨迹不是任意都能自动得到正确排序。。
