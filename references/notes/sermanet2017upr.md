# sermanet2017upr — Unsupervised Perceptual Rewards for Imitation Learning

阅读日期：2026-10-06。书目年份/venue：2017；RSS 2017（未将书目venue自动视作本次核验）。来源：[原始摘要/作者页面](https://arxiv.org/abs/1612.06699)；[书目正式版本](https://www.roboticsproceedings.org/rss13/p50.pdf)。版本：[Submitted on 20 Dec 2016 ( ), last revised 12 Jun 2017 (this version, v3)]。实际范围：**摘要初筛**，已读取完整可得摘要，不声称已读实验正文。来源记录：[_sources/sermanet2017upr.web.txt](_sources/sermanet2017upr.web.txt)。

- 原文问题：从少量demo自动识别关键中间步骤的perceptual reward。
- 原文方法/输入/监督：预训练视觉features，无显式subgoal标注，寻找辨别步骤的feature。
- 原文摘要报告的验证：真机两任务及human hand开门视频到robot RL。
- 阅读者判断/待核细节：少量特定任务demo和预训练features是条件；非通用process foundation model。
- 与基础工作的关系：阶段中间目标+视觉reward是早期基础，不能以此单独主张新颖性。

局限：上述实验数字是摘要中的作者报告，未核对表格、误差及完整比较条件；正文没有在此阶段读取的内容保持开放。
