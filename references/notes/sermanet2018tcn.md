# sermanet2018tcn — Time-Contrastive Networks: Self-Supervised Learning from Video

阅读日期：2026-10-06。书目年份/venue：2018；ICRA 2018（未将书目venue自动视作本次核验）。来源：[原始摘要/作者页面](https://arxiv.org/abs/1704.06888)；[书目正式版本](https://arxiv.org/pdf/1704.06888)。版本：[Submitted on 23 Apr 2017 ( ), last revised 20 Mar 2018 (this version, v3)]。实际范围：**摘要初筛**，已读取完整可得摘要，不声称已读实验正文。来源记录：[_sources/sermanet2018tcn.web.txt](_sources/sermanet2018tcn.web.txt)。

- 原文问题：多视角无标签视频的viewpoint-invariant行为表征。
- 原文方法/输入/监督：同步多view吸引、时间邻居排斥的metric loss，robot用单人类第三视角demo学行为。
- 原文摘要报告的验证：human pose模仿及pouring等真机RL reward。
- 阅读者判断/待核细节：同步多视角是训练信息，部署单view不等于训练也单view。
- 与基础工作的关系：提供multi-view/时序视觉reward基础，须透明比较数据输入预算。

局限：上述实验数字是摘要中的作者报告，未核对表格、误差及完整比较条件；正文没有在此阶段读取的内容保持开放。
