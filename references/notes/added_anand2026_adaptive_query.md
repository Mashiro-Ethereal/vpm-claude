# Adaptive querying for reward learning from human feedback

Anand, Nwagwu, Sabbe, Fitter, Saisubramanian；Frontiers in Robotics and AI。网页标注发表日期 2026-02-12，卷号为 12–2025，DOI 年份为 2025。补充检索，2026-10-06。

- 来源：[正式全文](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2025.1734564/full)。
- 实际阅读：完整摘要、引言方法/实验概述、§3 任务假设，以及讨论片段；未精读所有公式和实验表，属于方法初筛。
- 问题/方法：同时选择查询状态和人类反馈形式，权衡信息增益、反馈成本与得到回应的可能性，学习未建模副作用的惩罚。
- 验证：3 个仿真设置、12 人网格预实验、30 人 Kinova Gen3 用户实验；这里不将人类反馈效率的结果外推为纯视觉验证效率。
- 假设与边界：基础模型已足以完成主任务，缺失的是额外副作用；以不同形式的人工反馈为信息渠道。
- 对本项目的判断：按信息价值和成本安排奖励查询是已有原则。主动视觉奖励方向须体现机器人自身观察/动作提供证据、观察改变物理状态、以及实际任务收益，而不只是把人类查询换一种命名。
